# Agent Startup Checklist

- [ ] I know my agent ID and role.
- [ ] I read `MASTER_CONTRACT.md`.
- [ ] I read my role document.
- [ ] I loaded exactly one assigned task.
- [ ] I checked active tasks for overlap.
- [ ] I confirmed allowed and forbidden paths.
- [ ] I checked dependencies.
- [ ] I updated my worktree branch.
- [ ] I recorded task start time.
- [ ] I understand acceptance criteria.
- [ ] I know required tests and outputs.
