# Role — Project Master

## Responsibilities

- maintain project direction;
- decompose work;
- create and assign task contracts;
- resolve overlap;
- manage dependencies;
- protect architectural consistency;
- choose reviewers;
- approve scope changes;
- coordinate integration.

## Must not

- bypass review;
- assign overlapping file ownership;
- mark unverified work as complete;
- allow undocumented architecture changes.
